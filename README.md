# RoamCollie

旅遊分帳前端初版，以 React 19、Vite 6、Tailwind CSS 4 與 Lucide icons 製作。

## 啟動

```sh
npm install
npm run dev
```

使用開發伺服器顯示的網址；同一區網的手機可透過電腦 IP 與對應連接埠存取。

```sh
npm run build
npm test
```

## 功能

- 建立行程：名稱、目的地、出發日、天數、旅伴。
- 多行程切換；行程可編輯、刪除（至少保留一個）；支出可新增、查看、編輯與刪除。
- 選擇付款人、分類、日期、參與分攤的旅伴。
- 平均分帳、指定金額分帳，精確到分；平均分攤餘數依勾選順序分配。
- 分類與文字搜尋、旅伴收付餘額、建議轉帳。
- 手機底部導覽、響應式版面與原生 dialog 鍵盤焦點管理。
- localStorage 保存資料，首次提供標示為示範的京都行程。

## 後續串接

`src/ledger.js` 是獨立分帳運算；`src/main.jsx` 目前以 React state 與 localStorage 處理資料。後續可以將資料讀寫替換為 API，再由後端連接 Docker 內的資料庫。所有金額以整數分儲存，目前統一使用 TWD，不含匯率換算。

目前沒有帳號、遠端同步或實際付款功能；新增支出時可選擇任一旅伴作為付款人。建議轉帳只供核對，未提供已付款標記。清除瀏覽器資料將移除本機紀錄。

Logo 位於 `public/logo.png`。行程封面使用 Unsplash 遠端圖片；無網路時仍有綠色底色。
